# LaR Theme

Canonical visual identity namespace for **LaR Arquitetura e Interiores**.

G2 establishes the boundary only and intentionally does not import a new stylesheet, so the rendered site remains unchanged.

G4 will formalize the current visual language into semantic tokens for:

- mineral/light/dark surfaces;
- typography roles;
- borders and focus states;
- spacing/radii;
- motion duration/easing;
- image treatments.

Until G4, `app/globals.css` remains the active visual source of truth.
